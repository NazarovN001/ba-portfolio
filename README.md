# Telegram AI Mentor — ИИ-бот для обучения в Школе 21

## О проекте
Учебный проект Школы 21 (3 месяца, индивидуально). 
Разработал ИИ-агента, который помогает студентам с выбором направления обучения и карьерным ростом.

## Моя роль
- Спроектировал архитектуру бота
- Разработал 5 модулей (workflow, дайджест, анализ вакансий, ментор)
- Интегрировал с LLM API и Telegram Bot API
- Развернул на облачном сервере через Docker

## Выполненные задачи

### Задание 1: Настройка ИИ-агента
- Развернул n8n с помощью Docker на облачном сервере
- Настроил базовую архитектуру агента
- Изучил работу с LLM-моделями через API

### Задание 2: Проектирование workflow
- Спроектировал workflow взаимодействия пользователя с агентом
- Создал JSON-конфигурации для различных сценариев
- Протестировал различные подходы к промптингу
