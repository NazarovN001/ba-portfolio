#  AI Agent — Telegram-бот для обучения в Школе 21

ИИ-агент на базе LLM, который помогает студентам с выбором направления обучения, 
анализом вакансий и подбором учебных материалов.

## 🛠 Технологии
- Python, Docker
- LLM API (GPT / локальные модели)
- Telegram Bot API
- RAG (Retrieval-Augmented Generation)

##  Что умеет бот
- Подбирает направление обучения на основе интересов
- Присылает дайджест новых материалов по выбранному профилю
- Анализирует рынок вакансий и отслеживает требования
- Работает как персональный ментор

## 📦 Как запустить
1. Клонируй репозиторий: `git clone <url>`
2. Настрой переменные окружения в `.env`
3. Запусти через Docker: `docker-compose up`

## 📁 Структура проекта
- `src/` — основной код бота и агента
