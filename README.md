# Telegram AI Mentor — ИИ-бот для обучения в Школе 21

## О проекте
Учебный проект Школы 21 (3 месяца, индивидуально).  
Разработал ИИ-агента, который помогает студентам с выбором направления обучения и карьерным ростом.

## Моя роль
- Спроектировал архитектуру бота
- Разработал 5 модулей (workflow, дайджест, анализ вакансий, ментор)
- Интегрировал с LLM API и Telegram Bot API
- Развернул на облачном сервере через Docker

## Выполненные задачи

### Задание 1: Настройка ИИ-агента
- Развернул n8n с помощью Docker на облачном сервере
- Настроил базовую архитектуру агента
- Изучил работу с LLM-моделями через API

### Задание 2: Проектирование workflow
- Спроектировал workflow взаимодействия пользователя с агентом
- Создал JSON-конфигурации для различных сценариев
- Протестировал различные подходы к промптингу

### Задание 3: Дайджест новостей
- Реализовал функционал автоматического сбора новостей
- Настроил фильтрацию по интересам пользователя
- Интегрировал вывод в Telegram

### Задание 4: Анализ вакансий
- Разработал логику анализа рынка вакансий
- Реализовал структурирование данных о требованиях
- Создал систему сопоставления навыков пользователя с вакансиями

### Задание 5: Персональный ментор
- Добавил функционал персонального наставника
- Реализовал сценарии подбора учебных материалов
- Настроил систему обратной связи и улучшения ответов

## Результаты
- ✅ Развернут работающий Telegram-бот
- ✅ Интеграция с LLM через API
- ✅ Поддержка RAG (Retrieval-Augmented Generation)
- ✅ Модульная архитектура для масштабирования

## Технологии
- Python, Docker, n8n
- LLM API (GPT / локальные модели)
- Telegram Bot API
- RAG (Retrieval-Augmented Generation)

## Структура проекта
- `src/task1/` — настройка агента
- `src/task2/` — workflow дизайн
- `src/task3/` — дайджест новостей
- `src/task4/` — анализ вакансий
- `src/task5/` — персональный ментор
